## Traceability

-   Give each recorded decision a stable ID, for example: decisions
    (`DEC-001`).
-   Record the decision, date, owner/authority, rationale and status.
-   Link significant decisions to the supporting analysis in
    `03-decision-analysis` where one exists.
-   Reference the requirements, risks, architecture/design elements,
    configuration items and changes affected by the decision.
-   Preserve superseded decisions rather than silently replacing them;
    link the superseding decision.
-   The purpose is to show **the authoritative history of material
    engineering decisions and the rationale available when each decision
    was made**.

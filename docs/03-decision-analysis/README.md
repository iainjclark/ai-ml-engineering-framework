## Traceability

-   Give each material analysis a stable ID, for example: decision
    analyses (`DA-001`) and evaluated alternatives (`ALT-001`).
-   Reference the requirements, constraints, risks and assumptions that
    establish the decision criteria.
-   Record the alternatives considered, evaluation criteria, evidence,
    uncertainties, trade-offs and recommendation.
-   Link the selected outcome to the corresponding entry in
    `07-decision-log`.
-   Reference the decision from any architecture/design elements or
    controls that depend on it.
-   The purpose is to show **that important engineering choices were
    made deliberately, transparently and on evidence**.
